# 📈 AI Powered Stock Trading Platform

A full-stack web application that simulates a stock trading platform where users can manage their portfolio, track holdings and positions, maintain a watchlist, and view market information.

## 🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- 📊 Stock Market Dashboard
- ⭐ Stock Watchlist
- 💰 Buy & Sell Stocks
- 📁 Portfolio & Holdings Management
- 📈 Positions Tracking
- 📰 Market News
- 🤖 AI-powered Market Insights
- 👤 User Profile Management
- 🚪 Secure Logout

## 🛠️ Tech Stack

### Frontend
- React.js
- Bootstrap
- JavaScript

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB

### APIs & Services
- Finnhub API – Stock market data and news
- Google Gemini API – AI-powered market insights

### Authentication
- JSON Web Token (JWT)
- HTTP-only Cookies
